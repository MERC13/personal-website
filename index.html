Jul 2026

Counterfactual Action Editing with a World Model

Can a learned world model tell you which action made a robot fail? I trained an action-conditioned latent dynamics model — a transformer over DINOv2 features — on LIBERO manipulation rollouts, then used CEM to search for the minimal action edit that would have rescued a failed episode, replaying every candidate in MuJoCo to check it for real rather than trusting the model’s own prediction. The model does localise faults: AUROC 0.88–0.92 for flagging the failure window, and the learned critic ranks candidate edits above chance (0.62–0.71). But across eight configurations, nothing beat random edits unless it was handed the oracle fault window. It is published as a negative result with the full ablation table, because the gap between “has signal” and “is useful” is the entire finding.

Python · PyTorch · JAX · MuJoCo · LIBERO

Jun 2026

RL over a Frozen VLA’s Steering Interface

Fine-tuning a vision-language-action policy is expensive; steering one through its natural-language interface is not. I froze π0.5 and trained a clipped-PPO actor-critic with GAE over a categorical policy whose action space is a menu of per-task instructions — so the RL problem becomes “what should I tell the robot next,” not “what torques should it apply.” Most of the real work was infrastructure: a Modal-based rollout cluster with a hardware-aware local/cloud split, WebSocket serving for the frozen policy, and a unit-tested audit pipeline so every number in the results table traces back to the rollout that produced it.

Python · PyTorch · JAX · openpi / π0.5 · MuJoCo · Modal

Jun 2026

Lecture Assistant

Lecture audio streams in over WebSockets, goes to Deepgram for transcription, and lands in Redis Stack, which doubles as the low-latency vector store. An asyncio FastAPI orchestrator then runs Claude-backed agents that generate comprehension questions against the last few minutes of material while the lecture is still happening. Every stage is instrumented with OpenTelemetry into Arize AX, so when a question comes out wrong you can see which retrieval and which prompt produced it. The binding constraint was end-to-end latency — a question that arrives after the professor has moved on is worthless.

FastAPI · Redis Stack · Deepgram · Claude · Arize AX · Docker

With Ben Hung and Lucas Zheng. No public repo yet.

Fantasy Football Browser Extension

A temporal transformer that forecasts NFL player outcomes week by week, wrapped in the smallest product that could use it. Weekly histories run through a mixed numeric/categorical pipeline with per-feature learned embeddings, tuned with Optuna over nfl_data_py play-by-play data; position-specific models for QB, RB, WR and TE sit behind a Flask API that a Manifest V3 extension calls to overlay projections directly on top of the numbers ESPN and Yahoo are already showing you. On the weeks I backtested, it beat both platforms’ published projections.

PyTorch · rtdl · Optuna · nfl_data_py · Flask · JavaScript

Automated Research Digest

A weekly literature digest that runs itself. A containerised pipeline scrapes new preprints, parses PDFs with PyMuPDF, chunks and embeds them into Pinecone, retrieves against my interests, summarises with a local Ollama model, and emails the result through SendGrid. It runs as an ECS task on an EventBridge schedule, with logs in CloudWatch and images in ECR — no server to babysit and nothing running when it is idle. It has indexed on the order of 100,000 papers.

PyMuPDF · Pinecone · Ollama · Docker · AWS ECS · SendGrid

Jul 2026

Medical Diagnoses with Deep Learning

Two halves of one question: how far does transfer learning get you on a small, imbalanced medical dataset, and can you generate your way out of the imbalance? I fine-tuned VGG16 for binary pneumonia detection on the Kaggle chest X-ray set, applying class weighting to handle the skew, and reached 96% test accuracy. The second half is a DCGAN generator and discriminator trained on CIFAR-10 to synthesise images for dataset augmentation.

Python · Keras / TensorFlow · PyTorch

Nov 2025

Deep Q-Network for Atari, from Scratch

DeepMind’s 2015 Nature DQN, reimplemented without an RL library. Experience replay, an ε-greedy exploration schedule, a target network, and Bellman TD-error updates with gradient clipping — all written by hand against raw frames from the Arcade Learning Environment. Building the machinery yourself is the point: the paper’s hyperparameters stop looking arbitrary once you have watched training collapse without each one.

PyTorch · Gymnasium · ALE · NumPy · OpenCV
